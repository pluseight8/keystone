# Plugin UI extensions

Declarative Activity Bar, Command Palette, Context Menu, Sidebar, Settings, Object Action, Status and isolated View contributions are supported. Labels, icons, actions, namespaces and counts are quota bounded.

The DesktopShell owns tabs, panes, navigation, attribution, security, safety and confirmation UI. Plugins cannot cover protected screens or inject arbitrary DOM into Core. Mobile marks desktop-only views unavailable instead of showing a broken substitute.
