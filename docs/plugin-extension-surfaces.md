# Plugin extension surfaces

Supported surfaces are Tool, Skill, Model, Context, Search, Video, Music, Live, Calendar, File Handler, Object Renderer, Agent Capability, declarative UI, Notifications and Events. A surface grants no data permission by itself; each requested capability is separately reviewed and revocable.

Registration metadata is namespaced, revision/session bound, quota checked and removable. Stop, disable, quarantine and uninstall deactivate all registrations. Core owns aggregation, ranking, privacy, safety, attribution, confirmation and navigation.

Executable provider calls use the sandbox provider registry; executable functions are never persisted. Unknown plugin objects remain opaque and can be rendered when the add-on is later restored.
