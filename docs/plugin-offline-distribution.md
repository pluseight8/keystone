# Offline plugin distribution

Local files, USB bundles and reachable owned/P2P peers can provide a package without Internet. Offline packages follow the same limits, dependency lock, quarantine, integrity, signature, compatibility and owner-review lifecycle as network packages. If connectivity is unavailable after an owner requests an update, Keystone persists a bounded acquisition plan rather than retrying continuously.

Future mesh transports may carry opaque content-addressed availability and chunks. They do not expose relay chains, people, locations or install decisions.
