# Источники плагинов

Источники настраиваются владельцем и имеют opaque id, тип, reference, health и подсказку provenance. Known/authenticated source не делает все пакеты безопасными. Reserved Core ids может зарегистрировать только Core; display name не является идентичностью.

Discovery ограничен, работает только с metadata и изолирован timeout. Search не устанавливает, не включает и не выдаёт capabilities, а также не отправляет источнику Vault, Memory, чаты, контакты, календарь, location, topology mesh или secrets.
