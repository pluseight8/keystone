# Extension surfaces

Поддерживаются Tool, Skill, Model, Context, Search, Video, Music, Live, Calendar, File Handler, Object Renderer, Agent Capability, declarative UI, Notifications и Events. Тип поверхности сам по себе не выдаёт доступ к данным. Регистрация namespaced, привязана к revision/session, bounded и удаляется при stop/disable/quarantine/uninstall.
