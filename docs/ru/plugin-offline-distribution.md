# Offline-распространение плагинов

Local file, USB bundle или доступный owned/P2P peer могут дать пакет без Internet. Offline package проходит те же limits, dependency lock, quarantine, integrity, signature, compatibility и owner review. При отсутствии связи update request сохраняется как bounded acquisition plan без постоянных retry.

Будущая mesh-транспортировка может передавать opaque content-addressed availability/chunks, но не relay chain, людей, locations или install decisions.
