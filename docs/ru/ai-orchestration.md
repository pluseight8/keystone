# Приватная AI-оркестрация

Keystone оставляет помощника локальным по умолчанию. `AIOrchestrator` может
использовать локальный runtime или trusted-устройство Personal AI Mesh, чтобы
прочитать приватный контекст и собрать итоговый ответ. Внешние providers —
только необязательные workers для изолированных public-подзадач, а не сервер
персональных данных.

## Контракт делегирования

`DelegationPlan` содержит ограниченный список `AISubtask`. Подзадача имеет
нейтральный `objective`, идентификаторы источников и явное подтверждение
`safeForExternal`. Исходный пользовательский prompt в неё не попадает. Перед
каждой внешней подзадачей `SafeDelegationService`:

1. отклоняет неподтверждённую задачу, `PRIVATE`/`SECRET`-контекст, private
   system data, private tools и случайное совпадение с private-источником;
2. сам вызывает `AIEgressFirewall.assert('remote', ...)`;
3. отправляет payload только явно выбранной внешней модели;
4. отклоняет external tool intents и не выполняет/не пересылает их.

Redaction не считается согласием на передачу. Если сформулировать задачу без
private данных нельзя, она остаётся локальной/trusted или завершается fail
closed. Fallback внешнего provider не превращает private task во внешний
запрос.

`delegateMany` использует bounded concurrency, отмену и timeout на запрос.
Финальная сборка всегда выполняется локально или через
`PERSONAL_TRUSTED_COMPUTE`. Внешний результат — данные, а не authority.

## Режимы и provenance

- **Только приватно** — внешнее делегирование запрещено.
- **Сбалансированный** — безопасные изолированные public-подзадачи могут идти
  во внешний provider; private-контекст и финальная сборка остаются локально;
- **Сначала локальный** — сначала используется local/trusted execution, а
  внешний provider допускается только для такой же безопасной public-задачи.

Каждый результат содержит metadata-only provenance: локальный контекст,
планирование, делегирование, внешний результат и финальная сборка. Там есть
source IDs и data classes, но нет значений prompt или private tool output. UI
показывает `Обработано приватно` или `External AI использован только для
изолированной подзадачи`.

Используются существующие provider adapters и Personal AI Mesh поверх
Hyperswarm/Noise. Нового центрального AI-сервера Keystone, telemetry,
платежей, рекламы и public GPU sharing нет.
