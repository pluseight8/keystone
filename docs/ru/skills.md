# Skills

Skills — ограниченные декларативные процедуры поверх Keystone Tools. Tool — типизированная исполняемая capability. Plugin/Add-on — отдельная executable-платформа, описанная в [Plugins](plugins.md).

В Skills surface можно просматривать installed/imported пакеты, integrity и permissions, включать/отключать Skill, проверять updates/candidates и возвращаться к проверенной revision. Desktop command palette содержит Install Skill, Open Skills, Create Skill, Review Skill Candidates, Enable/Disable и Export Skill. Mobile показывает список и enable/disable через typed host adapter.

Получение SkillPackage через Chat, Shared Space или FileObject — только reference/import; установка всегда требует явного review. Полные инструкции загружаются только после bounded relevance routing, а не для всех установленных Skills.
