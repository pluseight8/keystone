# Матрица проверки платформ

Linux имеет реальные host/process/filesystem и локальные probes; Windows 11,
macOS, Android и iOS имеют typed boundaries, но физически в этом окружении не
проверены. Validation выполнена на Omarchy (Arch Linux-based distribution) с
Node v22.23.2, pnpm 9.15.0 и package engine >=22 <23.
