# Native Bluetooth / Нативный Bluetooth

`NativeBluetoothHost` models bounded scan, advertisement and connection lifecycles. The generic adapter reports unavailable without verified hardware integration. No social Identity is placed in radio advertisements; scan windows/results are bounded and cancellable.
