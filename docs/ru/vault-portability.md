# Переносимость Vault

Keystone хранит Markdown-заметки и обычные вложения как долговечный источник
истины Vault. Daily Notes, шаблоны, задачи, свойства и ссылки используют
переносимые соглашения Markdown/frontmatter; сохранённые запросы, закладки,
граф, Canvas и данные совместной работы являются ограниченными производными
sidecar-данными.

Открытие Vault в другом Markdown-редакторе остаётся безопасным: текст заметок и
обычные ссылки читаются, а Keystone-специфичные представления отображаются как
сохранённое определение или обычный текст. Потеря производного индекса или
кэша CRDT не удаляет пользовательский Markdown — индекс можно построить снова.

Эпохи ключей private Shared Vault и очередь репликации хранятся только через
зашифрованную host-boundary. Они не экспортируются как plaintext. Границы
импорта/экспорта должны сохранять object references и permissions, а не
копировать private content в публичные индексы.
