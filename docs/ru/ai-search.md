# AI-поиск и источники

Экран AI-контекста содержит запрос, выбор области и раскрываемые источники. Источник открывает исходный Keystone object; media-копия не создаётся. Badge показывает локальную обработку либо блокировку внешнего AI.

Поиск может связать DM с File и задачей Shared Space, Track с Shorts или Profile с Live. Blocked identities, удалённые объекты, отозванное членство и private Spaces без доступа отфильтровываются до передачи AI. Context budget ограничивает объём; omitted/truncated IDs доступны интерфейсу.

Источники — это provenance, а не выдуманные моделью ссылки. Citation принимается только если ID и метаданные совпадают с результатом resolver. Сырые payloads, история чатов и private media не отправляются внешнему provider. При отсутствии доказательств Keystone сообщает, что ничего не найдено.
