# Native capabilities / Нативные capabilities

Feature discovery использует `AVAILABLE`, `UNAVAILABLE`, `UNSUPPORTED`, `PERMISSION_REQUIRED`, `DEGRADED`. Core не делает capability detection через случайные exceptions. Security-critical unavailable features fail closed; optional hardware features fail soft.

Features: secure storage, filesystem, notifications, background execution, camera, microphone, audio, Bluetooth, Wi‑Fi Direct, LAN, USB, WebRTC, process sandbox, clipboard, external links, power, thermal and permission broker.
