# macOS release

Compilation and unsigned `.app`/DMG production require a macOS runner with
Node 22, pnpm 9.15.0, Rust stable, Xcode command-line tools, and Tauri
prerequisites. The updater stays disabled in development.

For an updater-enabled release, supply the real
`KEYSTONE_TAURI_UPDATER_PUBLIC_KEY` and signing secret, generate the ignored
release config with `pnpm release:prepare-desktop`, then build with
`--features updater --config src-tauri/tauri.release.conf.json`.

Signing, hardened runtime, notarization, stapling, and distribution require an
owner-provided Apple Developer Team, certificate, provisioning/notarization
credentials, and an Apple ID/App Store Connect workflow. None are generated by
this repository. Before signing, test the unsigned app on physical macOS for
launch, tray/global shortcut behavior, WKWebView, keychain behavior,
permissions, update UI, install/upgrade, and network/P2P/WebRTC flows.
