# Skills

Skills are bounded, declarative procedures on top of Keystone Tools. Tools are typed executable capabilities. Plugins/Add-ons are a future executable extension platform and are intentionally not implemented here.

Use the Skills surface to inspect installed/imported packages, review integrity and permissions, enable or disable a Skill, review updates and candidates, and roll back verified revisions. The desktop command palette includes Install Skill, Open Skills, Create Skill, Review Skill Candidates, Enable/Disable, and Export Skill. Mobile exposes the installed list, permission state, and enable/disable controls through a typed host adapter.

The current model is local-first and non-commercial. Receiving a SkillPackage through Chat, a Shared Space, or a FileObject is only a reference/import event; installation always requires an explicit review. Full instructions are loaded only after bounded relevance routing, never for every installed Skill.
