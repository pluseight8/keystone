# Native media devices / Медиа-устройства

Camera, microphone, audio and WebRTC are typed host boundaries with explicit permission/provenance. Current Linux package reports camera, microphone and native WebRTC unavailable unless an adapter is injected. No hardware enumeration or stable device fingerprint is exposed. WebRTC connectivity is not Identity authorization.
